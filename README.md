# Ghost Engineered by OCTOPODAMI® (GEBO)

With [Ghost](https://ghost.org/) Engineered by OCTOPODAMI® (GEBO), you can launch a Ghost stack pre-configured for reliability, maintainability, performance, and security.

Our engineers built this 1-Click Amazon Machine Image (AMI) for rapid deployment; a new server is usually ready in about 10 minutes on Amazon Web Services.

Instead of spending countless hours learning the details of a Ghost build, we've packaged our stack with everything you need to publish content on the world's leading cloud platform.

## Features

Ghost Engineered by OCTOPODAMI® (GEBO) uses the following technologies:

1. **Ghost**: Modern, open-source publishing platform
2. **Nginx**: Fast, lightweight web server with high performance
3. **Amazon Linux 2023**: AWS-optimised Linux distribution with enhanced security
4. **Node.js 22**: Current runtime for Ghost
5. **MySQL 8**: High-performance database with strong reliability
6. **Instance ID unlock**: Every server stays closed until you enter its EC2 instance ID
